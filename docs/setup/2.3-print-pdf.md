# Task 2.3: The print PDF

**Time:** about 10 minutes. **Cost:** ₪0.
**Do it on:** the Mac Mini.

**What you get at the end:**
- From an album you already built and looked at, the computer makes the **files for the printer**: `print-pages.pdf` (the inside pages) and `print-cover.pdf` (the front cover).
- The files show **exactly** the pages you saw in `album.html`, drawn sharp enough for print.
- A short **check**: it warns you if a photo is too small to print well in its spot.

> 🔒 **The print PDF is for the printer only.** Never send it to the customer (they get small watermarked previews, task 2.4).

> ⚠️ **The printer's rules are a first guess.** The printer isn't chosen yet (task S.2), so the files use the most common rules. They're all in one settings file, `album/printer.py`. When the printer sends its specifications, we change them there.

> **Words you'll see**
> - **Bleed:** a little extra picture (3 mm) around each page. The printer cuts it off, so there's never a thin white line at the edge of a page.
> - **Trim size:** the page's size after cutting (now 20×20 cm). The PDF pages are 20.6×20.6 cm: the trim size plus the bleed. The file tells the printer where to cut.
> - **DPI (dots per inch):** how sharp a photo prints. 300 is the print standard; under 200 can look soft; under 150 looks blurry.

---

## Step 1: Get the new code

```bash
cd ~/pashut-book && git pull
```

No new tools to install, and no need to restart the bot.

## Step 2: Build the album and look at it

As in task 2.2 (skip this if you just did it):

```bash
cd ~/pashut-book && .venv/bin/python album/build_album.py --order latest
```

Open it with the `open …` line it prints, and check it looks right.

## Step 3: Make the print files

```bash
cd ~/pashut-book && .venv/bin/python album/print_pdf.py --order latest
```

(For an album built from a folder, give the folder instead of `--order latest`.)

It takes a few seconds and ends with lines like:

```
✅ …/output/albums/1a2b3c4d/print-cover.pdf  (3 MB)
✅ …/output/albums/1a2b3c4d/print-pages.pdf  (60 MB)
```

Lines with ⚠️ or ❌ name a page and a photo that may look soft or blurry in print. ⚠️ is usually fine; for ❌, change the photo or tell the customer.

## Step 4: Look at the PDF

```bash
open ~/pashut-book/output/albums/
```

Open the album's folder, then `print-pages.pdf`. Zoom in on a face: it should be sharp. Photos and page colours go slightly past where the page will be cut; that's the bleed, on purpose.

✅ **Done when:** you have the two PDF files and they look like the album. The final test is when the chosen printer accepts them (after task S.2).

---

## What to ask the printer (task S.2)

Bring this list; the answers go into `album/printer.py` and `album/designs.py`:
1. Page size (trim size) and the number of pages allowed (minimum, maximum, multiple of 2 or 4).
2. Bleed (usually 3 mm) and a safe margin for text.
3. Resolution (usually 300 DPI) and colour: is RGB fine, or do they need CMYK?
4. One file, or the cover separately? For a **hardcover**, the cover wraps around the board and has a **spine** whose width depends on the page count: ask for their cover template.
5. **Hebrew books are bound on the right.** Do they bind on the right? (If not, the pages go in reverse order: we can add that.)

## If something goes wrong

- **"No album in …":** build the album first (Step 2).
- **"Photos missing for this album":** the album was built from other photos (for example the customer resent in HD). Build it again (Step 2), then Step 3.
- After rebuilding an album, the old print files are deleted automatically, so you never send an old version by mistake. Make them again with Step 3.
