**Time:** about 10 minutes. **Cost:** ₪0 (free plan).
**Do it on:** the Mac Mini.

**What you get at the end:** the bot's online "filing cabinet" is ready. Supabase will hold the orders (who ordered, which design, status) and the customers' photos while an album is being made. The Mac knows its address and its key.

> **Words you'll see**
> - **Supabase:** an online service that gives us a database (a smart table of orders) and file storage (for photos). Free up to 500 MB of data and 1 GB of files.
> - **Project URL:** the address of our Supabase project. Not secret.
> - **Secret key:** a password that lets the bot read and write **everything**, including all photos. It must stay only on the Mac.

## Step 1: Copy the secret key (3 min)

1. Go to **supabase.com/dashboard** → project **pashut-book**.
2. In the left menu, at the bottom: **Project Settings** (⚙️) → **API Keys**.
3. Under **Secret keys** there is a key named `default` that starts with `sb_secret_`. Click the 👁 or **copy** button to copy it.
   - If you don't see one, click **Create new secret key**, name it `mac-mini`, and copy it.
   - **Don't** use the "publishable" key (`sb_publishable_…`). That one is for websites, and the bot doesn't need it.

> ⚠️ **Never** paste the secret key into a chat (including with Claude), an email, or GitHub. If it ever leaks, go back to this page, delete it, and create a new one.

## Step 2: Put it in `.env` on the Mac (3 min)

> **Why can't I see `.env` in Finder?** Files whose name starts with a dot are hidden on a Mac. To see them in Finder, press **⌘ + Shift + .** (period). Press it again to hide them.

1. Open **Terminal** and run these 2 commands, one at a time. The first creates an empty `.env` file (or does nothing if it's already there). The second opens it in TextEdit.

```bash
touch ~/pashut-book/.env
```

```bash
open -e ~/pashut-book/.env
```

2. In TextEdit, add these two lines at the end (if the file is empty, just paste them):

```
SUPABASE_URL=https://jyfnxrktbpgklihastvc.supabase.co
SUPABASE_SECRET_KEY=
```

3. Paste your secret key right after `SUPABASE_SECRET_KEY=`, with **no spaces** and no quote marks. It should look like `SUPABASE_SECRET_KEY=sb_secret_abc123…`.
4. Save (**⌘ + S**) and close TextEdit.

Check it worked (this shows only the address line, not the key):

```bash
grep SUPABASE_URL ~/pashut-book/.env
```

## Step 3: Check that it works (1 min)

```bash
cd ~/pashut-book && python3 server/check_supabase.py
```

You should see **"✅ Connected to Supabase"**. If you see ❌, the message says what to fix (usually the key wasn't copied in full).

## Good to know

- **Free projects fall asleep after 7 days without use.** Until the bot is running, Supabase may pause the project and email you. Nothing is lost: open the dashboard and click **Restore**. Once the bot is live, it stays awake.
- **Photo privacy:** in task 1.3 we'll create a **private** photo storage area (a "bucket"), so no photo ever has a public link. Photos are deleted automatically after delivery.
- **Moving later:** if we ever leave Supabase, the database is standard PostgreSQL and can be copied out.
