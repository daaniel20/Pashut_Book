# Task 2.4: Watermarked previews in WhatsApp

**Time:** about 15 minutes. **Cost:** ₪0.
**Do it on:** the Mac Mini and your phone.

**What you get at the end:**
- When the bot finishes building an album, the customer gets **one** WhatsApp message: the cover picture, a short text, and a button **[📖 לצפייה באלבום]**.
- The button opens a **private web page** with the whole album as small pictures with a **PREVIEW** mark: the cover, page 1, then two pages per picture like an open book (2–3, 4–5 …), each with its page numbers, so the customer can say "page 5: …".
- Right after it, a message with two buttons: **[😍 אהבתי!]** and **[✏️ לשנות משהו]**.
  - "אהבתי" gets a short thank-you ("we'll be in touch about payment and shipping"). Payment itself is task 3.2.
  - "לשנות משהו" opens the same list as the summary (title, design, cover photo, add photos). After the change, the album is built again and a **new** link is sent. The old link stops working.

> 🔒 **Protecting the photos:**
> - The link has a long random code (like a password), so nobody can guess it. Only the customer gets it. If they forward it, whoever gets it can see the album, just as with forwarded pictures.
> - It stops working after **30 days** (`LINK_DAYS` in `server/preview_links.py`) and when the album is rebuilt.
> - Search engines are told not to list the page, and nothing else on the Mac can be opened through it.
> - Each page is only 700 pixels (about 90 DPI on a 20 cm page; print needs 300), with the PREVIEW mark across it 3 times. The print PDF never leaves the Mac.

> **Words you'll see**
> - **Spread:** two pages side by side, as you see them when the book is open.
> - **Link page:** the page is served by the bot on the Mac, through the Cloudflare Tunnel you already have (`https://bot.pashutbook.com/album/…`). No new service, no cost. If the Mac is off, the link doesn't open until it's back.

## Step 2: Try it on your phone

1. Write **אלבום חדש** to the test number and go through the whole conversation (design, cover photo, photos, title).
2. At the summary, wait. After the album is built (about a minute for 40 photos), you get the cover with the **📖 לצפייה באלבום** button, then the two buttons.
3. Tap the link button. Check: does the page open quickly? Are the pages in order, and the numbers easy to read? Is the mark visible but not annoying?
4. Go back to WhatsApp, tap **✏️ לשנות משהו**, change the title, and check that a new link arrives with the new title (and the old link now says it's no longer active).
5. Tap **😍 אהבתי!**.

You can also look at the pictures on the Mac without a phone: they are in the album's `preview` folder. The build command prints the line to open it:

```bash
cd ~/pashut-book && .venv/bin/python album/build_album.py --order latest
```

> Building by hand like this does **not** send anything to the customer. Only the bot sends the link.

## Good to know

- **Cost:** Meta charges only for "template" messages (messages a business starts outside the 24-hour window). Replies within 24 hours of the customer's last message, including pictures and links, are free. So the link doesn't save money; it's simply one tidy message instead of 14 pictures, and the pictures don't fill the customer's phone gallery.
- **If the customer is in the middle of a change** (for example typing a new title) when the album is ready, the link waits. The new album is built when they finish, and its link is sent then.
- **If the link fails to send**, the bot writes it in the log (`~/Library/Logs/pashut-book/bot.log`). Build and check by hand, then write to the customer yourself.
- **The 24-hour rule:** WhatsApp lets a business send free-form messages only within 24 hours of the customer's last message. Today the album is built right after the summary, so this is fine. If an album is ever sent much later (for example after a manual fix), it will need an approved message template (task 3.x).
- **How the mark looks** is set at the top of `album/preview.py` (`MARK`, `MARK_OPACITY`, `PAGE_PIXELS`). The page's words are in `server/texts/he.json` (`preview_…`).
- **Different web address:** if the bot's address ever changes (for example on a cloud server), set `PUBLIC_URL=` in `.env`.

## If something goes wrong

| What you see | What to do |
|---|---|
| The album is built (log says ✅) but no link arrives | Look in the log for "Could not send a message". A "Meta error" there explains why (for example an expired token: run `python3 server/check_whatsapp.py`). |
| Log says "previews wait" | The customer was changing something. The link comes after they finish. |
| The link opens "no longer active" | The album was rebuilt (a newer link was sent), or 30 days passed. |
| The link doesn't open at all | Is the bot running and the tunnel up? Open https://bot.pashutbook.com/health: it should say "ok". |
