# Task 2.1: Photo quality check

**Time:** about 20 minutes. **Cost:** ₪0.
**Do it on:** the Mac Mini, with your phone nearby.

**What you get at the end:** a tool that looks at a set of photos and marks each one:

| Mark | Meaning | Why |
|---|---|---|
| ✅ ok | Use it anywhere, even a full page | big and sharp |
| 🟡 small spots only | Use it only in a small spot on a page | lower resolution (e.g. sent without HD), or a bit soft |
| ❌ leave out | Don't use it | blurry, too small, can't be opened, or a **duplicate** (the same photo twice, or almost the same shot taken a second later; the best copy is kept) |

It also **sorts the photos by the date they were taken**, when the photos still have it. Photos sent normally in WhatsApp usually lose the date; then the order they were sent is kept (customers usually send them in order).

It doesn't change anything for the customer yet. Task 2.2 (layout) will use these marks to build the album.

> **Words you'll see**
> - **Pillow:** a free, widely used Python tool for opening and measuring photos. `pillow-heif` adds iPhone photos (HEIC).
> - **.venv ("virtual environment"):** a private box inside the project folder for extra Python tools like Pillow. It keeps them separate from the rest of the Mac. The bot doesn't need it; only the album tools do.

## Step 2: Make a test folder (10 min)

1. In Finder, make a folder on the Desktop called **test-photos**.
2. From your phone, AirDrop about **15 normal photos** into it.
3. Add some **bad** ones on purpose:
   - **2 blurry photos:** take them while moving the phone.
   - **The same photo twice:** in Finder, select a photo and press **⌘ + D** (duplicate).
   - **3 photos in a row** of the same thing (hold the shutter button, or tap fast).
   - **A photo without HD:** send yourself a photo in WhatsApp **without** HD, save it, and AirDrop it to the folder.

## Step 3: Run the check (2 min)

```bash
cd ~/pashut-book && .venv/bin/python album/check_photos.py ~/Desktop/test-photos
```

It prints a list in the Terminal and makes a report page with the photos. Open it:

```bash
open ~/pashut-book/output/quality-report.html
```

Green border = ok, yellow = small spots only, red = leave out. Under each photo you see why.

**Look for mistakes:** a good photo marked red, or a bad photo marked green. If you find any, tell Claude which photo and its "sharpness" number. The limits are at the top of `album/quality.py` and are easy to adjust.

## Good to know

- **The limits are a first guess.** "Full page" needs 2000 pixels on the long side, which suits an album of about 20×20 cm. When the printer and album size are chosen (S.2) and the test album is printed (S.4), we'll adjust them.
- **Sharpness** is measured on the sharpest parts of the photo, so a portrait with a soft, blurry background still counts as sharp.
- **Duplicates:** of two similar photos, the one with more pixels (and then the sharper one) is kept.
