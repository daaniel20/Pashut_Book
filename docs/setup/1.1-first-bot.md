# Task 1.1: The first bot ("Hello")

**Time:** about 45 minutes. **Cost:** ₪0.
**Do it on:** the Mac Mini, with your phone nearby.

**What you get at the end:** you write anything to the test number in WhatsApp, and within a few seconds the bot answers by itself:

> שלום! 👋
> זה הבוט של פשוט בוק.
> בקרוב נוכל ליצור כאן יחד אלבום תמונות מודפס 📖

> **Words you'll see**
> - **Webhook:** an automatic notice from Meta to our Mac: "a new message arrived". Meta sends it to an address we give it.
> - **System user:** a "robot user" inside your Meta business. Its access token **never expires** (unlike the 24-hour token from task 0.1).
> - **App secret:** a password Meta uses to "sign" every notice, so the bot can tell a real notice from a fake one.
> - **Verify token:** a password **we invent**. Meta repeats it once, to prove we own the address.

> ⚠️ Everything here is in the **testing** setup: the app **Pashut Album Test** under the older **headyhelmet** portfolio (see task 0.1). Only your registered phones can talk to it.

---

## Step 1: Get the new code on the Mac (1 min)

```bash
cd ~/pashut-book && git pull
```

## Step 2: Give the bot its own address (3 min)

1. In Cloudflare: **Zero Trust** → **Networks → Tunnels** → `mac-mini` → **Edit** (or the ⋯ menu → Configure).
2. Open **Public hostnames** (may be called **Published application routes**) → **Add a public hostname**.
3. **Subdomain:** `bot` · **Domain:** `pashutbook.com` · **Type:** `HTTP` · **URL:** `http://localhost:8000` → **Save**.

The bot's address is now **https://bot.pashutbook.com** (the old hello address keeps working too).

## Step 3: Create the permanent token (10 min)

1. Go to **business.facebook.com/settings** and pick the **headyhelmet** portfolio (top left).
2. **Users → System users → Add**. Name: `pashut-bot`. Role: **Admin**. Click **Create system user**.
3. With `pashut-bot` selected, click **Assign assets** (may be called **Add assets**):
   - **Apps** → `Pashut Album Test` → turn on **Full control** (Manage app).
   - **WhatsApp accounts** → the test account → turn on **Full control**.
   - Click **Save changes**.
4. Click **Generate token** (or **Generate new token**):
   - **App:** `Pashut Album Test`
   - **Token expiration:** **Never**
   - **Permissions:** tick `whatsapp_business_messaging` and `whatsapp_business_management`
   - Click **Generate token**.
5. **Copy the token now** (Meta shows it only once) and keep the page open for Step 5.

> 🔑 Never paste the token into any chat (including with Claude), an email or GitHub.

## Step 4: Copy the app secret (2 min)

1. Go to **developers.facebook.com/apps** → `Pashut Album Test`.
2. Left menu: **App settings → Basic**. Next to **App secret**, click **Show** (it asks for your Facebook password) and copy it.

## Step 5: Fill in `.env` (5 min)

1. Invent the verify token. This command makes a random one for you; copy what it prints:

```bash
python3 -c "import secrets; print(secrets.token_urlsafe(24))"
```

2. Open `.env` in TextEdit (it already has the Supabase lines from task 0.3):

```bash
open -e ~/pashut-book/.env
```

3. Add these lines at the end, and paste each value right after the `=` (no spaces, no quote marks):

```
WHATSAPP_PHONE_NUMBER_ID=
WHATSAPP_BUSINESS_ACCOUNT_ID=
WHATSAPP_ACCESS_TOKEN=
WHATSAPP_APP_SECRET=
WHATSAPP_VERIFY_TOKEN=
```

   - **Phone number ID** and **WhatsApp Business Account ID:** from your note in task 0.1. If you lost them: the app → **WhatsApp → API Setup** (Try it out). Use the IDs of **Pashut Album Test**.
   - **Access token:** from Step 3. **App secret:** from Step 4. **Verify token:** from point 1 above. **Keep the verify token handy** for Step 8.

4. Save (**⌘ + S**) and close TextEdit.

## Step 6: Check the WhatsApp settings (1 min)

```bash
cd ~/pashut-book && python3 server/check_whatsapp.py
```

You should see two ✅ lines: the token works (with the test number shown), and the app is connected to the WhatsApp account. If you see ❌, the message says what's wrong.

## Step 7: Start the bot (2 min)

```bash
cd ~/pashut-book && bash deploy/mac/install-bot-service.sh
```

It asks for your Mac password and ends with **"✅ Done. The bot is running."** It also removes the old test page from task 0.2 (the bot took its place and shows the same page). From now on the bot starts whenever the Mac turns on.

## Step 8: Tell Meta where to send messages (5 min)

1. **developers.facebook.com/apps** → `Pashut Album Test` → **WhatsApp → Configuration**.
2. Under **Webhook**, click **Edit**:
   - **Callback URL:** `https://bot.pashutbook.com/webhook`
   - **Verify token:** the one you invented in Step 5
   - Click **Verify and save**. If it saves without an error, Meta reached the bot ✅.
3. Under **Webhook fields**, click **Manage**, find **messages**, and click **Subscribe**.

## Step 9: The test ✅ (1 min)

1. On the Mac, watch the bot's log live (press **Control + C** to stop watching; the bot keeps running):

```bash
tail -f ~/Library/Logs/pashut-book/bot.log
```

2. On your phone, write **שלום** to **Pashut Book TEST**.
3. Within a few seconds you get the bot's answer, and the log shows `Got a text message` and `Reply sent`.

The log shows only the last 3 digits of a phone number and never the text or photos of a message (privacy).

## Something went wrong?

| Problem | What to do |
|---|---|
| **Verify and save** gives an error | 1) The verify token in Meta and `.env` must be exactly the same. 2) Open https://bot.pashutbook.com on your phone: you should see the test page. If not, redo Step 2. 3) Check that the bot runs: `curl http://localhost:8000/health` should print `ok`. |
| No answer in WhatsApp and **nothing new in the log** | Meta isn't sending us messages. Check that **messages** is subscribed (Step 8.3), and run Step 6 again. |
| Log says **"wrong signature"** | The app secret in `.env` is wrong (or is from another app). Copy it again (Step 4), then run Step 7 again. |
| Log says **"Meta refused the reply (error 401)"** or mentions an expired token | The token is wrong or is the 24-hour one. Redo Step 3 with **Never**, then Step 7. |
| Log mentions **131030** ("recipient not in allowed list") | The test number can only write to your registered phones. Add the phone in **WhatsApp → API Setup → To → Manage phone number list** (task 0.1, Step 5). |
| Log mentions **131031** ("Business Account locked") | The app is under an unverified portfolio. Make sure you're using **Pashut Album Test** (headyhelmet), not the new Pashut Book portfolio. |
| Log says **"Missing in .env"** | One of the 5 lines in Step 5 is empty or misspelled. Fix it, then run Step 7 again. |
| The menus look different from this guide | Meta changes its website often. Look for the same words (System users, Generate token, Webhook, Callback URL). Send me a screenshot **with tokens and secrets hidden**. |

**Where are the logs?** `~/Library/Logs/pashut-book/bot.log`
