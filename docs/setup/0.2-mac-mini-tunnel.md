# Task 0.2: Mac Mini setup + Cloudflare Tunnel

**Time:** about 1–1.5 hours. **Cost:** a domain name, about **$10–11 a year** (about ₪40). Everything else is free.
**Do it on:** the Mac Mini, with your phone nearby.

**What you get at the end:** the Mac Mini is on all the time, comes back by itself after a power cut, and has a **permanent internet address** (for example `https://hello.pashutbook.com`) that opens a small test page on the Mac. In task 1.1, WhatsApp will send customers' messages to an address like this.

> **Words you'll see**
> - **Terminal:** the Mac app where you type commands. Open it with **⌘ + Space**, type `Terminal`, press Enter. To run a command, paste it and press Enter.
> - **Homebrew:** a free "app store for commands". It installs the tools we need with one line.
> - **Domain:** a website name you own, like `pashutbook.com`.
> - **Cloudflare Tunnel:** a free Cloudflare service. A small program on the Mac opens a safe, private "pipe" out to Cloudflare. People on the internet reach the Mac **only through that pipe**. You don't open anything on your home router, and your home address stays hidden.

---

## Step 1: Install Homebrew (10 min)

1. Open **Terminal**.
2. Go to **brew.sh**, copy the command under "Install Homebrew", paste it into Terminal, and press Enter.
3. It asks for your **Mac password**. When you type it, nothing appears on screen. That's normal. Type it and press Enter.
4. At the end, Homebrew shows **"Next steps"** with 2–3 commands. **Copy and run them** (they let Terminal find Homebrew).
5. Check: run `brew --version`. You should see a version number.

## Step 2: Install Python, Cloudflare's program, and GitHub's tool (5 min)

```bash
brew install python cloudflared gh
```

- **python:** the language the bot is written in.
- **cloudflared:** Cloudflare's program for the tunnel.
- **gh:** GitHub's tool, to download this project to the Mac.

Check: run `python3 --version`. You should see `Python 3.1…`.

## Step 3: Download the project to the Mac (5 min)

1. Run `gh auth login`. Choose **GitHub.com** → **HTTPS** → **Login with a web browser**. Copy the code it shows, press Enter, and approve in the browser.
2. Download the project into your **home folder**:

```bash
gh repo clone daaniel20/Pashut_Book ~/pashut-book
```

> **Why the home folder and not Documents?** macOS blocks background programs from reading Documents, Desktop and Downloads. The bot runs in the background, so it lives in `~/pashut-book` (you can see it in Finder → Go → Home).

3. Try the test page by hand:

```bash
cd ~/pashut-book && python3 server/hello.py
```

Open **http://localhost:8000** in Safari on the Mac. You should see "✅ השרת של פשוט בוק עובד". Then go back to Terminal and press **Control + C** to stop it.

## Step 4: Keep the Mac awake, and turn it on after a power cut (3 min)

Run this one command (it asks for your password):

```bash
sudo pmset -a sleep 0 disksleep 0 autorestart 1 womp 1
```

What it means: never sleep (`sleep 0`), never stop the disk (`disksleep 0`), **start by itself after a power cut** (`autorestart 1`), and wake up for network activity (`womp 1`). The screen can still turn off; that's fine.

Check: run `pmset -g`. You should see `sleep 0` and `autorestart 1`.

Also in **System Settings → General → Software Update → Automatic Updates**: turn **off** "Install macOS updates" (it would restart the Mac at random times). Keep "Install Security Responses" **on**. Update macOS by hand when it suits you.

### FileVault and power cuts (please read)

**FileVault** encrypts the Mac's disk. Check it in **System Settings → Privacy & Security → FileVault**.

- If FileVault is **on**, after a power cut the Mac turns on but **waits for your password** before anything runs. The bot is down until you type it.
- **My recommendation: keep FileVault on.** The Mac will hold children's photos while albums are made, so encryption matters. Power cuts are rare, and Meta keeps retrying messages it couldn't deliver, so customers' messages aren't lost; they arrive once you unlock the Mac.
- Later, a small **UPS** (a battery box for the Mac and router, about ₪300–500) can keep it running through short power cuts. Not needed now.

## Step 5: Make the test page start by itself (3 min)

```bash
cd ~/pashut-book && bash deploy/mac/install-hello-service.sh
```

It asks for your password and ends with **"✅ Done"**. From now on, the test page starts whenever the Mac turns on (even before anyone logs in), and restarts by itself if it crashes. (The script creates a "LaunchDaemon", which is macOS's built-in way to run a background program at startup.)

## Step 6: Buy a domain on Cloudflare (10 min, about $10–11/year)

> **Why we need a domain:** WhatsApp needs a **permanent** address for the bot. Cloudflare's free tunnel gives a permanent address only on a domain you own. The domain is also useful later for a landing page and a business email.

1. Create a free account at **dash.cloudflare.com** (use your business email if you have one). Turn on two-factor authentication: profile → **Authentication**.
2. In the left menu, open **Domain Registration → Register Domains**.
3. Search for a name. My suggestion: **pashutbook.com**. If it's taken, try `pashut-book.com` or `getpashutbook.com`. Prefer **.com**: Cloudflare sells it at cost, without markup. (Cloudflare doesn't sell `.co.il`.)
4. Pay with a card, and choose **auto-renew** so you don't lose it.

The domain is ready in Cloudflare within a few minutes.

## Step 7: Create the tunnel (10 min)

1. In Cloudflare, open **Zero Trust** from the left menu (it may be called **Cloudflare One**). The first time, it asks you to pick a team name (anything, e.g. `pashutbook`) and a plan: choose **Free** ($0). It may ask for a card even for the free plan; it won't be charged.
2. Go to **Networks → Tunnels → Create a tunnel**.
3. Type: **Cloudflared**. Name: `mac-mini`. Click **Save tunnel**.
4. Choose **macOS**. Cloudflare shows a few commands. **Skip** `brew install cloudflared` (you did it in Step 2). Copy the command that starts with:

   ```
   sudo cloudflared service install eyJ...
   ```

   Paste it into Terminal and press Enter.

   > 🔑 The long text after `install` is the tunnel's **secret key**. **Don't paste it into any chat** (including this one) or document. Using it in Terminal is fine.

5. Back on Cloudflare's page, at the bottom, the tunnel should show **Connected** within a minute. Click **Next**.
6. Add the address (the section may be called **Public hostnames** or **Published application routes**):
   - **Subdomain:** `hello`
   - **Domain:** your new domain
   - **Type:** `HTTP`
   - **URL:** `localhost:8000`
7. Click **Save**.

The `service install` command makes the tunnel start by itself whenever the Mac turns on, just like the test page.

## Step 8: The test ✅ (2 min)

1. On your phone, **turn off Wi-Fi** (so you use mobile data, not the home network).
2. Open **https://hello.pashutbook.com** (with your domain).
3. You should see "✅ השרת של פשוט בוק עובד" and the time on the Mac.

**Extra test (recommended):** restart the Mac (Apple menu → Restart). If FileVault is on, type your password. **Don't open Terminal or anything else.** Wait 2 minutes and reload the page on your phone. It should work again by itself.

## Something went wrong?

| Problem | What to do |
|---|---|
| `brew: command not found` | You skipped the "Next steps" at the end of Step 1. Close Terminal, open it again, and run them. |
| `python3` opens a window asking to install "developer tools" | Run `brew install python` again, then close and reopen Terminal. |
| The page on the phone says **Error 1033** | The tunnel isn't running. Check that the tunnel shows **Connected** in Cloudflare. If not, run the `sudo cloudflared service install …` command again (copy it fresh from Cloudflare). |
| The page on the phone says **502 Bad Gateway** | The tunnel works, but the test page isn't running. Run Step 5 again. Check that **http://localhost:8000** opens in Safari on the Mac. |
| The phone can't find the address at all | Wait 5 minutes (new addresses take a little time), and check the spelling of the subdomain and domain in Step 7. |
| The install script says the project is in Documents/Desktop | Move the folder to your home folder, as in Step 3. |
| The menus look different from this guide | Cloudflare changes its website often. Look for the same words (Tunnels, Public hostname, Connected). Send me a screenshot **with the secret key hidden**. |

**Where are the logs?** The test page writes a short log here: `~/Library/Logs/pashut-book/hello.log`.
